# App Profile browser presentation adoption

The Server consumer adopts published `@lapis-notes/app-profile@0.3.0` through
the normal `^0.3.0` registry range. The npm tarball exposes the reviewed
`browser-presentation` entry point containing the shared appearance,
theme-colour, install-host, and window-controls adapters.

The Server retains hosted connection, recovery, offline data, and session
authority. Only browser presentation mechanics move to the Notes-owned public
contract. Focused host tests, frozen installation, dependency intake, the built
hosted PWA journey, and exact image publication remain the delivery evidence.
